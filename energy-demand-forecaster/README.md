# Energy Demand Forecaster

An end-to-end machine learning project to forecast hourly regional electricity demand using historical data from the U.S. Energy Information Administration (EIA).

## Objectives
- Collect and preprocess hourly electricity demand data.
- Analyze daily, weekly, and seasonal patterns.
- Engineer predictive time-series features.
- Compare baseline forecasting methods with LightGBM.
- Evaluate forecasting accuracy using MAE and RMSE.
- Visualize actual and predicted electricity demand with Plotly.

## Technologies
Python, pandas, NumPy, scikit-learn, LightGBM, Plotly, Jupyter Notebook

## Data Source
U.S. Energy Information Administration (EIA)

https://www.eia.gov/opendata/

## Project Workflow
1. Data collection and preprocessing
2. Exploratory data analysis
3. Feature engineering
4. Baseline and machine learning forecasting
5. Model evaluation and visualization
